## Анализ неклассифицированных документов

### Проблемы классификации
1. **Сложные названия файлов**: Многие файлы имеют сложные названия с номерами, датами, которые не соответствуют простым паттернам
2. **Сокращения и аббревиатуры**: Много специфических сокращений для строительной отрасли
3. **Нестандартные названия**: Использование фирменных обозначений и шифров
4. **Дата-ориентированные названия**: Много файлов с датами, которые не соответствуют типам документов

### Примеры типичных неклассифицированных названий
- Файлы с числовыми шифрами: `34367-25-изм1`, `36008-25`, `34946-25`
- Файлы с датами: `27.02.2026`, `18.03.2026`, `24.02.2026`
- Библиотечные файлы: `lib.0000-ПП-РЕН-МЖ25-СПС_27.02.2026`
- Файлы с длинными шифрами: `1415-2026-177эт.pdf.sig`, `1402-2026-9102229117-170эт.pdf.sig`
