## 12. Рекомендации для дальнейшей обработки

### 12.1. Индексация документов для RAG

#### Приоритетные папки для индексации:
1. **РД** (Рабочая документация) - наиболее важные документы
2. **СПС** (Строительные проектные решения)
3. **ТУ** (Технические условия)
4. **Согласования** - Важно для отслеживания статуса
5. **Паспорта** - Техническая информация об объектах

#### Типы файлов для индексации:
1. **PDF файлы** - Легко извлекать текст
2. **Word файлы** - Легко извлекать текст
3. **Excel файлы** - Требуется специальная обработка (таблицы)
4. **DWG файлы** - Требуется конвертация в PDF или OCR

#### Классификация документов:
- Улучшить классификацию по названиям файлов
- Добавить распознавание шаблонов (например, "РД-XX-XXX", "СПС-XXX")
- Использовать контекст папок для классификации

### 12.2. Структура базы данных

#### Рекомендуемая схема:
- **Проекты** (Objects) - Строительные объекты
- **Документы** (Documents) - Файлы с метаданными
- **Связи** (Relations) - Связи между документами
- **Версии** (Versions) - Версии документов
- **Теги** (Tags) - Категории и типы документов

### 12.3. Парсинг DWG файлов

#### Варианты обработки:
1. **Конвертация в PDF** - Использовать AutoCAD или dwg2pdf
2. **Извлечение метаданных** - Использовать библиотеки для чтения DWG
3. **OCR** - Для растрированных чертежей

### 12.4. Обработка больших объемов

#### Рекомендации:
1. **Очередь обработки** - Использовать очередь для последовательной обработки
2. **Пакетная обработка** - Обрабатывать файлы пакетами
3. **Приоритизация** - Сначала обрабатывать важные документы
4. **Кэширование** - Кэшировать результаты обработки

### 12.5. Интеграция с Mia

#### Возможные интеграции:
1. **Автоматическая индексация** - При добавлении новых документов
2. **Запросы на естественном языке** - Поиск документов
3. **Связь с проектами** - Связывание документов с проектами
4. **Уведомления** - О новых документах или изменениях

## 13. Заключение

Объем данных в папке "5_Стройка" **значительно превышает** первоначальные оценки:
- **Ожидалось**: ~100 папок, ~10,000 файлов
