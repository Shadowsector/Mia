# 🚀 Быстрая установка Mia PM OS с llama.cpp

## Вариант 1: Автоматическая установка (рекомендуется)

Запустите:
```bash
cd C:\mia
python scripts\auto_install_llama.py
```

⚠️ Загрузка модели может занять 10-30 минут (около 8 GB)

## Вариант 2: Ручная установка (быстрее)

### Шаг 1: Установить llama.cpp

1. Откройте: https://github.com/ggerganov/llama.cpp/releases
2. Скачайте последний релиз: `llama-bXXXX-bin-win-cuda-cu12.2.0-x64.zip`
3. Распакуйте в: `C:\llama.cpp\`
4. Убедитесь, что есть `C:\llama.cpp\llama-server.exe`

### Шаг 2: Скачать модель Qwen 2.5 14B

1. Откройте: https://huggingface.co/Qwen/Qwen2.5-14B-Instruct-GGUF
2. Скачайте: `qwen2.5-14b-instruct-q4_k_m.gguf` (около 8 GB)
3. Сохраните в: `C:\models\`

### Шаг 3: Создать ярлык

```bash
cd C:\mia
create_shortcut.bat
```

### Шаг 4: Запустить

Дважды кликните по ярлыку **"Mia PM OS"** на рабочем столе

## ✅ После установки:

1. Mia автоматически запустит llama.cpp при старте
2. В GUI увидите информацию о модели:
   - Model: qwen2.5-14b-instruct
   - Context: 8192 tokens
   - GPU Layers: 35
   - Threads: 8
3. Можно переключаться между моделями через кнопку "🔄 Switch Model"
