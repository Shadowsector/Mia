# Mia Construction Project Management OS - Agentic Tool-Calling Architecture

## Summary
Design a dynamic, agentic architecture for Mia - a local AI-driven Construction Project Management OS that operates through native Tool Calling (Function Calling) capabilities. The system uses autonomous Agent Loop instead of slash commands, optimized for implementation by smaller local LLMs (Gemma 3 12B / Qwen 3 Coder 14B via Ollama) on single-GPU systems (RTX 5060).

## Architecture Decisions (Clarified)

### Scale & Deployment
- **Projects**: 50+ concurrent construction objects
- **Users**: 10+ users (mix of admins, site managers, workers)
- **Deployment**: Local server with centralized orchestration

### Technology Stack Decisions (Agentic Architecture)
- **Architecture Pattern**: Autonomous Agent Loop with Native Tool Calling
- **Tool Selection**: LLM-driven autonomous tool selection (no routing)
- **Task Execution**: Unified priority-based SQLite task queue
- **Worker Pool**: Single-threaded execution (zero VRAM collisions on RTX 5060)
- **Vector Database**: ChromaDB (built-in persistence, metadata management)
- **STT**: Hybrid approach (GPU CUDA preferred, CPU quantization fallback)
- **Context Awareness**: Thread context + temporal awareness (system_current_time)
- **Conflict Resolution**: Immediate critical alerts for high-priority conflicts
- **Version Control**: Hybrid approach (configurable per document type)
